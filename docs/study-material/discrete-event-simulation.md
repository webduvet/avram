# Discrete-event simulation

- [SimPy documentation](https://simpy.readthedocs.io/en/latest/) — **free** — Process-based DES in Python; resources/queues for cutoff windows, auth timeouts, settlement cycles.
- [FoundationDB — Simulation and Testing](https://apple.github.io/foundationdb/testing.html) — **free** — Canonical deterministic simulation testing write-up (single-threaded cluster sim + fault injection).
- [Pierre Zemb — Diving into FoundationDB’s Simulation Framework](https://pierrezemb.fr/posts/diving-into-foundationdb-simulation/) — **free** — Implementation-level DST deep dive (Sim2, BUGGIFY, reproducibility).
- [Banks, Carson, Nelson, Nicol — *Discrete-Event System Simulation* (5th ed.)](https://www.pearson.com/en-us/subject-catalog/p/Banks-Discrete-Event-System-Simulation-5th-Edition/P200000003161) — **paid textbook** — ISBN-13 **978-0-13-606212-7** (US Pearson); also **978-1-292-02437-0** (Pearson New International). Buy/library — do **not** use pirate PDFs.
- [Amazon listing — Banks DES (5th)](https://www.amazon.com/Discrete-Event-System-Simulation-Jerry-Banks/dp/0136062121) — **paid** — Convenient purchase/ISBN check for the same book.
