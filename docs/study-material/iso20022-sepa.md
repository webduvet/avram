# ISO 20022 & SEPA

- [ISO 20022 — About the standard](https://www.iso20022.org/about-iso-20022) — **free** — Official methodology, repository, and catalogue overview *(WebSearch-verified; site may block some egress)*.
- [ISO 20022 Message Definitions (search pacs.008)](https://www.iso20022.org/iso-20022-message-definitions?search=pacs.008) — **free** — Catalogue entry for FIToFICustomerCreditTransfer (pacs.008) with MDR/XSD downloads.
- [ISO 20022 — Business Application Header (BAH)](https://www.iso20022.org/catalogue-messages/additional-content-messages/business-application-header-bah) — **free** — head.001 context for wrapping pacs/camt messages.
- [EPC — SEPA Credit Transfer rulebook & IGs](https://www.europeanpaymentscouncil.eu/what-we-do/sepa-payment-schemes/sepa-credit-transfer/sepa-credit-transfer-rulebook-and) — **free downloads** — SCT scheme rules + implementation guidelines (ISO 20022 subsets).
- [EPC — SEPA Direct Debit Core rulebook & IGs](https://www.europeanpaymentscouncil.eu/what-we-do/sepa-payment-schemes/sepa-direct-debit/sepa-direct-debit-core-rulebook-and) — **free downloads** — SDD Core rules / IGs for pull payments and mandates.
- [EPC — SEPA Instant Credit Transfer rulebook & IGs](https://www.europeanpaymentscouncil.eu/what-we-do/epc-payment-schemes/sepa-instant-credit-transfer/sepa-instant-credit-transfer-rulebook) — **free downloads** — SCT Inst <10s scheme; pairs with TIPS for settlement simulation.
- [SWIFT — ISO 20022 for Dummies (campaign / ebook)](https://www.swift.com/campaign/iso-20022/iso-20022-dummies) — **free ebook (registration)** — Best free narrative intro to MX / CBPR+ concepts *(WebSearch-verified)*.
- [SWIFT Smart training platform](https://www.swift.com/myswift/services/training/swiftsmart) — **included in institutional SWIFT fee / not publicly free** — 700+ e-learning modules for SWIFT users with BIC-linked accounts.
- [SWIFT — ISO 20022 training FAQ](https://www.swift.com/standards/iso-20022/iso-20022-faqs/training) — **mixed free/paid** — Clarifies free Smart self-learning vs payable instructor-led / certification exams.
