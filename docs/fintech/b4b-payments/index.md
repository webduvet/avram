# B4B Payments

Card issuing / BIN sponsorship / prepaid EMI. **Not a bank.** Trading name of Payment Card Solutions (UK) Limited (UK EMI), UAB B4B Payments Europe (Lithuanian EMI), and B4B Payments (USA) Inc. (US programme manager — Cross River is the issuer).

Official site: [b4bpayments.com](https://www.b4bpayments.com/c)

**Not this firm:** dissolved **PCS B4B LTD** (CH 11220347, previously named B4B PAYMENTS LTD), or generic B2B usage. See [Integrator baseline](integrator-baseline.md#disambiguation).
